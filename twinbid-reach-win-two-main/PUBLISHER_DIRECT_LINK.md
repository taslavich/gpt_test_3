# Direct Link для паблишеров

В «Рекламных кодах» выберите Direct Link, укажите название, тип трафика и устройства. После создания кабинет покажет ссылку, которую можно скопировать на кнопку или другой элемент. JS-загрузчик не нужен.

Изменение фронтенда подготовлено для следующего дополнения к API:

- `GET /api/publisher/ad-codes`: в существующий `data` добавить `supported_formats: ["popunder", "direct_link"]`, когда публичный обработчик и создание Direct Link готовы. Без этого поля прежний Popunder работает как раньше, а создание Direct Link недоступно.
- `POST /api/publisher/ad-codes`: принять `{"format":"direct_link","name":"Моя ссылка","traffic_type":"mainstream","device":"all"}`. Поля Popunder `trigger_click`, `frequency_minutes` и `max_per_session` для ссылки не передаются.
- В объекте Direct Link для списка, создания, просмотра, обновления и дублирования вернуть обычные идентификаторы и состояние кода, `format: "direct_link"` и `direct_link_url` — полный публичный HTTPS-адрес. Дубликат получает собственную ссылку. Фронтенд не конструирует URL из идентификатора и не подставляет адрес SDK. Если ссылки нет или она некорректна, копирование недоступно.
- При открытии ссылки сервер без авторизации посетителя находит код, проверяет его активность и ограничения, подбирает рекламу и выполняет переход. Учёт трафика и связь со статистикой по коду остаются на сервере. Публичный маршрут и правила обработки отсутствия рекламы определяет бэкенд.

Публичный обработчик, генерация адреса и учёт переходов должны быть реализованы в бэкенде. Этот архив содержит фронтенд.
