# Кабинет паблишера — интеграция с реальным API

Основа: `TwinBid-publishers-advertisers-v19-source(1).zip`. Контракт: `FProj227.zip`, `docs/publisher/API_MATRIX.md` и соответствующие обработчики.

Все закрытые страницы Publisher подключены к реальным API через прежний JWT HTTP-клиент. Удалены локальные бизнес-данные, генерация ID/short_code, демонстрационная статистика и выплаты. Ошибки не подменяются успешными пустыми результатами.

Коды — только Popunder, с явным Adult/Mainstream без третьего значения или автоматического выбора. PATCH использует version, опускает неизменённый traffic_type и обрабатывает 409. Дублирование, активность, архивирование и диагностика серверные. Код установки использует public_script_url и short_code backend, включая стабильный SDK.

Сайты и зоны обнаруживает сервер. Статистика использует реальные reports, группировки и фильтры, полные server totals/CTR и effective hourly UTC boundaries. Баланс отображает отдельные ledger-поля, без локальных начислений. Выплаты TRC20/ERC20 используют UUID и тот же request_id при сетевом повторе; двойное нажатие блокируется, отмена остаётся только у оператора. Настройки реквизитов и уведомлений сохраняются в backend.

Рекламодательские исходники, общая авторизация, роли, маршруты, стили, backend и RTB не менялись. Сборка production использует существующий флаг VITE_USE_MOCK=false. Подробности ENV, запуска и тестирования: README_PUBLISHERS.md.
