# TwinBid

Frontend for the TwinBid advertising platform and advertiser dashboard.

## Local development

Requirements: Node.js and npm.

```sh
npm install
npm run dev
```

The development server is available at `http://localhost:8080`.

## Production build

```sh
npm run build
npm run preview
```

## Technology

- Vite
- TypeScript
- React
- shadcn/ui
- Tailwind CSS
